WHAT YOU MUST DO MANUALLY
-------------------------
Run steps 1-2 on your computer in the project folder (needs Node.js; log in to Cloudflare when asked).

1) Apply the database migrations to the EXISTING database (do not create a new one):

       npx wrangler login
       npx wrangler d1 migrations apply earth-adventure --remote

   Answer "y" when asked. This creates the tables and loads your current trips.
   (Run it only once; it remembers which migrations were applied.)

2) Add the admin setup secret. Pick a long random value (at least 16 characters) and keep it:

       npx wrangler secret put ADMIN_SETUP_TOKEN --name earth1

   (Or in the Cloudflare dashboard: Workers & Pages -> earth1 -> Settings -> Variables and Secrets -> Add,
    type "Secret", name ADMIN_SETUP_TOKEN.)

3) Check the e-mail secrets. The booking e-mail needs these two secrets on the Worker. If they were
   already set before, leave them as they are. If not, add them (values come from integrations/google-apps-script/SETUP.md):

       npx wrangler secret put BOOKING_WEBHOOK_URL --name earth1
       npx wrangler secret put BOOKING_WEBHOOK_SECRET --name earth1

   Without them bookings are still saved in the database and shown in the dashboard, but no e-mail is sent
   (the dashboard marks such bookings "e-mail not delivered" and has a "Resend e-mail" button).

4) Upload the updated project to GitHub (extract the ZIP over your repository folder, or apply the patch:
       git apply earth-adventure-d1.patch
   then commit and push).

5) Deploy: Cloudflare builds and deploys automatically from GitHub (Workers Builds for "earth1").
   If your project is not connected, run:  npm install --legacy-peer-deps  &&  npm run build  &&  npx wrangler deploy
   IMPORTANT: if the build log shows no "d1_databases" / DB binding, open Workers & Pages -> earth1 ->
   Settings -> Bindings and add a D1 binding named DB pointing to earth-adventure.

6) Create your administrator account (once):
   open  https://YOUR-SITE/admin  -> enter the ADMIN_SETUP_TOKEN, choose a username and a password
   (at least 10 characters, letters and numbers). After that, the page is a normal login.

DAILY USE
  /admin -> Trips: add / edit / hide / delete trips, prices, images (upload or pick), descriptions (EN + AR)
  /admin -> Trips -> a group trip -> Departures: dates, times, seat capacity, open/closed
  /admin -> Bookings: search, filter, change status, cancel (frees the seats), notes, resend e-mail
  Changes appear on the website immediately - no code change or redeploy.

IF YOU FORGET THE ADMIN PASSWORD
       npx wrangler d1 execute earth-adventure --remote --command "DELETE FROM admin_users"
  then open /admin again and repeat step 6 (the ADMIN_SETUP_TOKEN secret is still needed).
